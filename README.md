# Cost Bar Ruler Plus（费用条尺子 Plus）

> **本发行版基于 [Z_06 / ArknightsCostBarRuler](https://github.com/ZeroAd-06/ArknightsCostBarRuler) 修改，由 威猛先生 维护。**
> 原项目采用 MIT 许可，原始版权归 Z_06 所有；本发行版保留全部原始版权声明与第三方许可（见 `LICENSE` / `LICENSES/`）。
> **这是第三方修改版，不是官方版本**，遇到问题请反馈到[本仓库 Issue](https://github.com/wekapipo-378/arknights-cost-bar-ruler-plus/issues)，不要打扰原作者。
>
> 维护者：威猛先生（[B 站](https://space.bilibili.com/440985091) · [GitHub](https://github.com/wekapipo-378)）

一个为《明日方舟》设计的悬浮窗工具，通过观察费用条的变化来测量当前关卡内的帧数，帮助你复刻那些卡帧的极限操作。核心分析引擎与截图后端来自原项目，本发行版重做了界面与交互层。

当前版本：`v2.3.2-mod.1`　可执行文件：`CostBarRulerPlus.exe`

---

## 相对原版做了什么

| 模块 | 原版 | 本发行版 |
|---|---|---|
| 设置界面 | 悬浮右键菜单里的若干项 | **独立 Win32 设置窗口**：校准 / 外观 / 快捷键 / 关于 四页，底部 保存 / 确定 / 取消 |
| 缩放 | 固定档位，选中即生效 | **50%–200% 可手输**，点保存/确定后才生效；设置窗口自身也跟着缩放 |
| 轴列表 | 列表 + 基础操作 | 行内改名、**点击标题改名**、注释编辑、记录帧后实时刷新、窗口任意位置可拖动 |
| 悬浮窗 | 帧数 / 计时 / 标记 | 新增：当前轴名、自动暂停预留提示、当前帧注释、下一标记帧号 |
| 快捷键 | 无 | **3 个全局热键**：计时 / 记录帧标记 / 切换自动暂停 |
| 计时器 | 重置有跳变；改预留帧数会重置计时 | 重置立即 `00:00:00`；改预留帧数不再重置；调节计时器时自动关闭自动暂停 |
| 联网 | 匿名统计上报 + 联网更新检查 | **全部移除**，程序不访问任何外部服务器 |

## 快速开始

### 下载运行

到 [Releases](https://github.com/wekapipo-378/arknights-cost-bar-ruler-plus/releases) 下载最新的 `CostBarRulerPlus-<版本>-win64.zip`，解压后直接运行 `CostBarRulerPlus.exe`。

- 会弹 **UAC 管理员授权**，这是正常的：读取游戏 / 模拟器窗口需要提权。
- 目录里必须保留 `icons/`、`ruler/locales/`、`LICENSE`、`LICENSES/`，否则会缺图标或界面文字变成键名。
- ⚠️ **不要和原版放在同一个文件夹**：两版都会读写同目录下的 `config.json` / `calibration/`，会互相覆盖。

### 从源码构建

前置要求：较新的 Rust 稳定工具链（edition 2021）、Windows 10 / 11。

```powershell
cargo build --release -p ruler-app        # 产物 target\release\CostBarRulerPlus.exe
.\build.ps1                               # 或：自动打包到 dist\CostBarRulerPlus\
.\build.ps1 debug                         # 快速迭代构建
```

`build.ps1` 会顺手把 `icons/`、`ruler/locales/`、`LICENSE`、`LICENSES/` 一起放进 `dist\CostBarRulerPlus\`。

### 数据目录

配置与运行时数据默认放在**启动时的工作目录**：

```
<exe 所在目录>\
├── config.json          # 配置
├── calibration\         # 校准文件
├── axes\                # 轴（帧标记）文件
└── log\<时间戳>_<pid>\  # 每次启动一个会话目录（app.log、可选 CSV / MKV）
```

可用环境变量覆盖：`ARKNIGHTS_RULER_CONFIG_PATH`、`ARKNIGHTS_RULER_CONFIG_DIR`、`ARKNIGHTS_RULER_CALIBRATION_DIR`、`ARKNIGHTS_RULER_DATA_DIR`、`ARKNIGHTS_RULER_LOG_DIR`。

## 使用说明

### 1. 首次配置向导

第一次启动会弹出配置向导：

1. 选择连接类型：**MuMu 模拟器 12 / 雷电模拟器 9 / Windows（电脑版）/ 通用 ADB**（另有调试用的手动模式与虚拟截图器）。
2. 按提示填安装路径、实例序号或 ADB Device ID；PC 版点“扫描窗口”选中明日方舟窗口。
3. 向导会扫描可用目标、给出实时预览与平均截图延迟，选一个能用的。
4. 点“保存并启动”，配置写入 `config.json`。

> 向导窗口可以拖动、可以缩放，底部按钮始终可见。

### 2. 首次校准

1. 打开悬浮窗（托盘图标或托盘右键 → 设置）。
2. 设置窗口默认停在**校准**页，点「新建」。
3. 进入任意关卡，**保持费用条可见**（正常速度即可，不用慢速）。
4. 悬浮窗此时显示“进入关卡后点击此处校准”，点一下它开始采集，等进度跑完。
5. 完成后悬浮窗开始实时显示帧数，新校准会自动成为使用中的配置。

> 费用回复速率变化时，在「校准配置」里换一份，或新建一份重新校准。
> 想了解“前 10 费不准 / 第 11 费 31 帧”这个现象，见[费用条边界周期分析](docs/cost-bar-boundary-cycle.md)。

### 3. 设置窗口

左栏是四个页面，底部是 **保存 / 确定 / 取消**：

- **保存**：提交当前修改并保持窗口打开。
- **确定**：提交并关闭。
- **取消 / Esc / 标题栏 ×**：把“显示模式 / 缩放 / 自动暂停预留帧数”回滚到打开窗口时的值再关闭。

**校准页**

| 分组 | 内容 |
|---|---|
| 校准配置 | 列表默认高亮**使用中**的那条（`*` 前缀）。选择 / 重命名 / 删除 / 新建；删除立即生效，删掉当前配置后会自动选中下一条 |
| 计时器 | `-周期`、`-1 帧`、`重置`、`+1 帧`、`+周期`、`撤销重置` |
| 计时器调节 | 显示当前时间（`分:秒:帧`），可输入 `01:02:03` 或直接输入帧数，点「设定」应用；「重置」归零 |
| 自动暂停 | 自动暂停的**预留帧数**（默认 3，可为负数，见下文） |

**外观页**

- 帧数显示：`0 / n-1`、`0 / n`、`1 / n` 三种数法。
- 缩放：50%–200%，可以从下拉里选，也可以直接手输（`110` 或 `110%`），**点保存 / 确定后才生效**。

**快捷键页**

- 三行：**计时**（圈速）、**记录帧标记**、**切换自动暂停**。
- 点按钮 → 按钮显示 `…` → 按下想要的组合键（如 `Ctrl+Shift+M`）即绑定。
- 按 **Backspace** 取消绑定（清空）。初始全部未绑定。
- 是**全局热键**，游戏在前台时也能用；若组合键被系统或其它软件占用，日志里会有 `could not be registered` 警告。

**关于页**

应用名、版本、署名、配置路径（完整路径，长路径自动换行）、打开项目主页、我的 B 站。

### 4. 悬浮窗怎么读

```
┌─────────────────────────────────┐
│ 轴名                    -3  ⏸  │ ← 左上：当前轴名（仅重命名过的轴会显示）
│  00:00:00           123 / 450   │ ← 右上：自动暂停预留提示（-N / +N / 0）
│                       +12       │ ← 主：全局计时（分:秒:帧）
│ 帧号  注释                      │ ← 右下：下一个标记帧号
└─────────────────────────────────┘  ← 左下：当前帧 + 该帧注释
```

- **左上角琥珀色**：当前使用的轴名（`config.active_axis` 有值时显示，默认名“轴1”之类不显示）。
- **右上角琥珀色**：自动暂停已开启时的预留提示。正数显示 `-N`（提前 N 帧），负数显示 `+N`（延后），`0` 显示 `0`。未开启暂停模式时整块不显示。
- **左下角琥珀色**：当前帧号；当**当前帧正好等于某个标记帧**时，后面会跟上该标记的注释。
- **右下角琥珀色**：下一个标记的帧号（没有后续标记时为空）。

**悬停悬浮窗**（运行中）会出现工具栏：`电源`（退出）/ `设置` / `旗`（圈速）/ `书签+`（记录当前帧为标记）/ `计时器`（开关自动暂停）。

**鼠标操作**

- 左键拖动：移动悬浮窗（位置会记住）。
- 右键：没有使用中的配置、或正处在“进入关卡后点击此处校准”时 → 打开设置（校准页）；轴窗口开着时 → 关闭轴窗口；运行中 → 打开轴列表；否则 → 打开设置。
- 左键点击（准备校准状态）：开始校准。
- 托盘右键：设置 / 轴列表 / 退出。

### 5. 轴列表窗口

- 列表显示所有轴文件与其中的标记数量；双击/点击一行打开该轴。
- **改名**：点一行进入行内编辑，或**直接点标题**改名；点窗口任意其它位置即保存，Esc 取消。
- **注释**：点帧行右侧的注释区域编辑，回车保存。
- **记录帧**：悬浮窗上点 `书签+` 或按全局快捷键，标记会写入当前轴文件，列表在 250ms 内自动出现新行。
- 顶部按钮：返回 / 跟随 / 置顶；底部：新建轴 / 复制 / 删除。
- 窗口可拖动到任意位置、可缩放，尺寸会被记住。

### 6. 自动暂停与预留帧数

自动暂停会在“标记帧 - 预留帧数”的位置向游戏发送一次 `ESC`。

| 预留值 | 行为 |
|---|---|
| `3`（默认） | 提前 3 帧停 |
| `0` | 正好在标记帧停 |
| `-5` | 延后 5 帧停（显示为 `+5`） |

- 调整预留帧数**不会**重置计时。
- 调节计时器（设定/重置/±按钮）时会**自动关闭**自动暂停。
- 「暂停模式」开关：悬浮窗工具栏上的计时器图标，或用快捷键。

> 说明：程序无法做到“零延迟”停表——采集→分析→发键本身有几帧延迟，预留帧数就是用来补偿这个的。想更早停就把预留值调大，想更接近标记帧就调小。

## 调试与录制

普通使用用不到这一节。

- **`--debug`（或 `-d`）启动**：强制打开配置向导并展开调试面板，可开启
  - 下次录制一次截图视频（MKV，体积很大）
  - 录制分析数据（CSV）
  - 超级详细日志
  - 虚拟截图器（从录好的视频重跑分析，不用连模拟器）
- **`ruler-recorder`**：独立录制工具，最高帧率同时录无损 HEVC 视频 + 逐帧分析 CSV（需要 `ffmpeg` 在 PATH）：

  ```powershell
  cargo run --release -p ruler-recorder -- -c config.json -o recordings -d 60
  ```

- **`ruler-verifier`**：离线校验器，拿录制好的视频跑一遍分析核对结果：

  ```powershell
  cargo run --release -p ruler-recorder --bin ruler-verifier -- <视频文件>
  ```

- **HUD 预览**（不开游戏看界面，会在仓库根目录生成 `hud_*.png` / `wizard.png`）：

  ```powershell
  cargo run -p ruler-app --example hud_preview
  ```

- 每次启动都会写 `log\<时间戳>_<pid>\app.log`；开了 CSV / MKV 也会落在同一目录，方便整包发出来排查。
- `RUST_LOG` 是开发者覆盖手段，日常排查优先用 `--debug` 面板里的详细日志开关。

## 本地 API

运行中的程序在 `127.0.0.1:2606` 提供本地接口：

- **WebSocket**（`ws://127.0.0.1:2606/`）：状态变化时推送快照，也可接收 `getSnapshot`、`getFrame`、校准、配置、计时器、显示模式、悬浮窗和退出等命令。
- **HTTP 快照**（`GET http://127.0.0.1:2606/`）：一次性拉当前状态 JSON，适合不想常驻连接的工具。

> 字段、命令与 fallback 规则详见 **[API.md](docs/API.md)**。

## 项目结构

Cargo workspace，三个 crate：

```
CostBarRulerPlus/
├── Cargo.toml              # workspace 根配置
├── build.ps1               # 构建 + 打包脚本（release / debug）
├── docs/                   # 延伸文档与 API 说明
├── crates/
│   ├── ruler-core/         # 核心库：截图、分析、引擎（跨二进制复用）
│   │   └── src/
│   │       ├── capture/    # 截图后端：adb / mumu / ldplayer / windows / replay
│   │       ├── analysis/   # 费用条分析：校准、扫描、ROI、映射、战斗状态
│   │       ├── config.rs   # 配置读写
│   │       └── engine.rs   # 帧检测引擎
│   ├── ruler-app/          # 桌面应用：Slint（悬浮窗）+ 原生 Win32（设置 / 轴 / 向导）
│   │   ├── ui/             # Slint 界面（hud / axes / wizard / menu / theme）
│   │   └── src/            # 悬浮窗、托盘、worker、API、设置窗口、配置向导…
│   └── ruler-recorder/     # 调试录制器 + ruler-verifier 离线校验器
├── icons/                  # 托盘 / HUD 图标（含 Material Symbols）
├── ruler/locales/          # 本地化翻译（zh_CN / en_US）
└── LICENSES/               # 第三方许可证原文
```

> 设置窗口、轴列表窗口、配置向导的宿主窗口都是**原生 Win32 窗口**（设置窗口的客户区全部由原生控件拼成），只有悬浮窗本身仍由 Slint 软件渲染。

## 已知限制

程序在以下环境下无法工作，这与版本无关：

- 部署费用已达到上限（费用条满了就不动了）。
- 部署费用无法自然回复（如剿灭作战）。
- 部署费用回复被锁定（如第 15 章“活性态萨卡兹术师结晶”锁费）。

## 出问题怎么办

1. 关掉重开一次。
2. 删掉工作目录里的 `config.json`，重新走配置向导。
3. 用 `--debug` 启动，按需开启 **超级详细日志**（必要时再开 CSV）。
4. 把 `log\<时间戳>_<pid>\` 整个文件夹 + 一句“当时在哪个页面做了什么”发到 [Issues](https://github.com/wekapipo-378/arknights-cost-bar-ruler-plus/issues)。

> 杀毒软件可能误报：本程序是**未签名**且要求管理员权限的 exe，报毒概率不低。介意的话请自行用沙箱运行或放弃使用。
